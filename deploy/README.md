# 第一代部署模板存档

本目录从 Tweet-Watcher v3.5.0 继承，用于理解第一代的代理、来源隔离和服务配置。文件中的域名、端口 8787、服务名和路径属于第一代，**不是第二代部署配置**，不要将它们直接应用到正在运行的旧服务。

第二代当前为开发骨架，默认在 `127.0.0.1:8788` 预览，采集和发送关闭；本轮没有创建第二代 systemd 服务或公网代理。后续部署模板将在完成采集适配、独立存储与迁移验收后单独建立。

参见 [开发指南](../docs/DEVELOPMENT.md) 和 [开发方案](../docs/V2_DEVELOPMENT_PLAN.md)。
