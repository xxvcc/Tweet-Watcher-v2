独立复核另纠正了一个修复过程中的状态问题：提交失败仅取消旧任务，不广播未落盘的尝试版本；配置/状态接口在恢复完成后同步实际版本，因此只读模式也不依赖 worker tick 才能恢复一致状态。

真实浏览器截图复核发现 SSE 重试错误可能误报健康 HTTP 状态，已修正并增加回归。截图脚本也改为等待抽屉动画完成后再检查布局和截图，手机设置截图限于视口，避免把动画中间帧或视口之外的背景当成界面结果。

配置事务是前向恢复语义。若保存时返回“提交未确认”，存储恢复后已持久化的意图可能自动完成，操作者应重新载入核对。原有第二代 config/secrets/outbox 文件继续可读；未完成事务包含凭据、权限 0600，已列入 Git 忽略。不要将事务记录放入诊断报告，也不要在它尚未完成时降级到不支持事务的旧代码。
