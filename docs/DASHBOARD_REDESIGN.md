# 首页与设置界面

更新：2026-10-30。首页、设置及复评后的细化均已实现并上线；当前运行状态以维护交接为准。本页记录实际界面与数据口径；测试和上线证据见[验证摘要](VERIFICATION.md)及[升级记录](archive/2026-10-30-ui-upgrade.md)。

## 布局与视觉

延续灰绿色背景、白色/深绿色面板与琥珀色强调，统一圆角、边框、留白、按钮高度和线性图标。修正说明文字紧贴按钮、诊断面板与来源卡片视觉不一致的问题。通用间距类放在组件规则之后，避免 `.sec-h` 覆盖顶部间距。

桌面首页左侧为监控来源，右侧为运行概况与最近活动；手机依次为指标、运行概况、来源和活动。顶部指标为监控来源、今日推送、待发送、预计下次检查，运行时长放在概况底部。没有预览时显示“本次运行暂无推送”，不保留大块空白；无历史数据时不绘制迷你图。

运行概况将 X 会话、历史补采、AI 翻译和 Telegram 队列放在同一面板。会话详情按需展开，异常摘要始终可见；各来源卡片展示类型、待发数量和补采阶段/已保存页数。活动默认突出重要记录，可切换全部或仅异常；不改变后端日志保留策略。

## 设置分组

设置采用桌面宽抽屉与手机全屏布局。桌面左侧导航，手机顶部为明确标注五个分类的选择框；内容独立滚动，底部保存操作固定可见。

| 分组 | 内容 |
|---|---|
| 监控来源 | 账号、帖子与回复、List、搜索，检查频率与筛选 |
| X 登录会话 | 默认凭据、额外会话和会话验证 |
| 推送与翻译 | Telegram、非中文翻译、hi 测试、媒体与内容补充 |
| 查询工具 | List 成员预览导入、推文详情与对话 |
| 安全与环境 | 访问密码、采集环境检查 |

已有来源默认显示名称、类型、频率、每页条数与筛选摘要，点击展开编辑；新建空白行直接展开。去掉重复标题和外层面板嵌套。折叠不销毁字段、不清草稿；保存后按来源身份保留展开状态。

切换分类只切换可见性，保留原表单节点与草稿，不自动保存。底部明确显示已载入、未保存、保存中、已保存或远端冲突。保存检查所有分类；非法输入自动切到对应分类，展开必要的高级选项并聚焦。后台配置更新继续保护正在编辑的草稿，冲突处理沿用版本校验。

hi 测试继续使用当前输入，不保存配置、不启用翻译，回复按纯文本显示。X/Telegram 测试沿用既有保存草稿和运行模式限制；新增标签导航不能绕过认证、CSRF、请求取消、独立忙碌状态或删除待发队列确认。

## 数据口径

- **今日推送**：上海日期当天且仅本次进程运行期间，按一条推文的所有部分完成确认计数，不是 Telegram 分段数，不是跨重启完整日统计。
- **待发送**：来自后端队列诊断；数据缺失或过期显示待确认，不能推断为零。
- **预计下次检查**：按来源间隔估算，不包含会话冷却、退避及排队等待。
- **最近成功**：仅代表会话历史请求成功，日期在展开详情中，不保证此刻始终可用。未知、凭据未配置、停用、限流和错误分别表达。
- **补采进度**：只展示真实阶段、已保存页数/条数，没有可信总量时不画完成百分比。
- **AI 已启用**：配置状态，不代表连通性验证。队列为空同样不能证明 Telegram 连通。
- 最近推送预览与活动展示来自有限运行状态；没有预览不证明 X 没有新帖。

本次升级不引入持久每日统计或完整历史浏览功能，不改变采集、投递、认证和状态格式。

## 验证要求

实际后端浏览器覆盖深浅主题、1440/390/320px、五类设置、键盘导航、草稿跨页保留、隐藏页非法输入定位、保存及 hi 测试。状态覆盖未知、暂停、会话异常/限流、补采和积压；保留 SSE 及 HTTP 轮询、凭据脱敏、认证代次和并发测试回归。合成外部对端与真实 X/AI/Telegram 验收明确区分。


## 复评后的细化

2026-10-30 用户已授权实现并上线验证，具体结果记录于[细化记录](archive/2026-10-30-ui-polish.md)。

- 常读正文采用 13–14px，辅助说明以至少 12px 为目标；加强浅色辅助文字及状态颜色对比，保留现有灰绿色与琥珀色方向。
- 已有来源折叠为摘要，编辑时展开；新增来源直接进入编辑，减少多来源管理的滚动距离。
- 手机通过“设置分类”下拉框直接访问所有五类设置，导航不计入未保存修改；桌面继续使用键盘可访问的分类标签。
- 来源和活动中的异常先展示短说明，再展开完整原始原因；已知限流、认证、分页覆盖等按实际错误映射，未知错误保持通用表达。未知消息接收结果不宣称肯定未送达。
- 刷新状态、新增活动或筛选日志时保留已展开的异常详情；活动缓存继续有界，退出后清理，原始日志和错误以纯文本呈现。

验证覆盖折叠字段校验自动展开、导航/草稿/焦点、保存后的展开状态、异常详情保留、真实旧浏览器缓存升级与深浅主题三种屏宽。
