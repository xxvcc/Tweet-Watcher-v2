监控来源

添加关注的账号、列表和搜索，调整检查频率与内容筛选。

来源与筛选说明
条数=每页请求条数，抓取会保留完整返回页；频率=自动监控间隔（≥30 秒）。修改后请保存；只读模式仅支持手动测试。
筛选只影响以后采集的新记录；包含词任一匹配，排除词任一匹配则不推送。帖子类型可重叠，取消任一相关类型即不推送。修改规则不会重新推送历史内容。
更改来源标识或“帖子与回复”范围视为替换来源：保存后建立新基线，并移除旧来源的待发送队列。需要保留旧队列时，请新增一行。

X 登录会话

管理采集使用的登录凭据，并验证最近一次请求是否可用。

X 默认登录会话

F12 → Application → Cookies → x.com。已保存的留空即保持不变。
验证会访问该目标，成功仅代表最近这次请求可用。

额外 X 登录会话

登录会话与监控来源不同。已有凭据留空保留；删除会话并保存会删除其凭据。代理可选，须填写端口，仅支持不含用户名密码的 HTTP(S) 地址。

Telegram 推送

AI 翻译

结合正文文字和 X 语言标记判断；纯中文跳过，混合内容保留中文、翻译外语部分。Telegram 同时保留原文和译文，翻译失败时继续推送原文。仅在 live 模式下调用 AI。
使用兼容 OpenAI Chat Completions 的 HTTPS API；需要翻译的正文会发送至所填服务。
已保存的 Key 不会显示，留空即保持不变。更换 API 地址时需重新填写 Key。
使用当前填写的地址、模型和 Key 发送 hi，留空 Key 时使用已保存的 Key。不保存配置，也不启用翻译；仅在 live 模式下可用。
